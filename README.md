# Yo Agronomist Simple Version

This is a simple static version of Yo Agronomist for quick preview and trial display.

## What it includes
- Single-page web app
- Crop and district advisory demo
- No backend
- No database
- Easy GitHub upload
- Easy deployment on Vercel, Netlify, or GitHub Pages

## Files
- index.html
- styles.css
- script.js

## How to use
1. Upload this folder to GitHub
2. Deploy it on Vercel or Netlify
3. Share the live link with trial users
